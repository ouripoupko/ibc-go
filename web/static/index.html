Connect

This page works with your contracts on this node. You sign in your browser wallet: the node never holds your key. Each transaction asks for your signature. Reading is signed by a reading session instead: a key this browser makes and you approve once, which can only read, only on this node, for 8 hours.

Any browser wallet for Ethereum keys works, for example MetaMask, Rabby, Coinbase Wallet, Trust Wallet, Frame, or the wallet built into Brave. Your agent is your key, not the wallet app: the same key in another wallet is the same agent. Smart-contract wallets, such as Safe, do not work, because ibc needs a key's own signature.
